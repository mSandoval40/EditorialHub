# EditorialHub: Ruta Hacia Lanzamiento

## Objetivo

Cerrar la brecha entre una plataforma funcional en desarrollo y una plataforma lista para operar en vivo con riesgo controlado.

## Etapa 1. Cerrar flujos criticos

- registro y verificacion de correo
- login y recuperacion de contrasena
- perfil de socio colaborador
- publicacion de obras
- revision admin
- catalogo
- compra
- biblioteca
- reseñas
- regalías y solicitud de pago

## Etapa 2. Endurecer operacion

- validar permisos y bloqueos
- revisar mensajes de error
- cubrir estados vacios
- asegurar consistencia entre frontend y backend
- mejorar trazabilidad administrativa

## Etapa 3. Preparar servicios reales

- Stripe live
- correo SMTP real
- URLs publicas reales
- secretos y variables de entorno de produccion
- base de datos de produccion

## Etapa 4. Preparar operacion de vivo

- checklist de lanzamiento
- monitoreo minimo
- respaldos
- procedimiento de recuperacion
- rutina operativa admin

## Etapa 5. Ejecutar pruebas de lanzamiento

- pruebas end-to-end como usuario lector
- pruebas end-to-end como socio colaborador
- pruebas end-to-end como admin
- regresiones sobre compra, biblioteca y regalías

## Entregables asociados

- auditoria de brechas
- checklist de produccion
- matriz de pruebas
- documentacion de despliegue y operacion
